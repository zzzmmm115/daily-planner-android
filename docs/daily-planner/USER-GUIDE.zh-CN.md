# 日程清单：文字导入版

版本：15.13-daily.1，基于 Tasks.org。安装包：`daily-planner-text-import-v1.apk`。

## 安装与中文

把安装包传到手机，用文件管理器打开安装。应用名为“日程清单”，英文系统可能显示“Daily Planner”。它使用独立包名 `org.tasks.daily`，可以与原 Tasks.org 同时安装，两者各自保存任务数据。

第一次打开可以选择“继续但不同步 / Continue without sync”，使用本地清单。若界面仍是英文，进入任务清单右上角菜单 → App settings → Look and feel → Language → 简体中文 → 中国。

本版沿用原 App 的任务数据模型：时间安排保存为带开始、截止时间的待办；无时间条目只带日期。界面中的“截止”是原 App 对任务时间的名称。

## 从哪里导入

任务清单右上角菜单 → **文字导入日程**。

也可以从其他 App 分享多行纯文字到本应用，会进入导入页面。单行分享保持原来的单项新建流程。

## 时间安排示例

下面仅为格式示例，日期可以自行修改。

```text
日期：2026-10-28
08:00-09:00 复习统计信号分析
09:15-10:00 CMOS：独立分析一个电路
20:30-21:00 整理水声笔记
```

## 条目清单示例

```text
日期：2026-10-28
- [ ] 英语到期复习
- [ ] 整理水声笔记
    完成标准：列出两个疑问
1. 下载课程要求的 Quartus
```

可混合两种格式。也支持普通逐行列表、中文编号、Markdown 时间表、全角冒号，以及“日期：明天 / 后天”。完整日期最可靠；其他复杂日期表达请在预览中手动改为明确日期。

跨日结束请明确写出，例如 `23:00-次日00:30 阅读` 或 `23:00-24:00 阅读`。

## 导入步骤

1. 选择目标清单；未注明日期的任务使用页面上的默认日期。
2. 粘贴文字，点击“预览待办”。
3. 核对每项的任务名称、日期、开始、结束及备注，直接修改字段；不需要的项取消勾选。
4. 处理红色错误提示。没有时间的任务保持开始和结束为空。
5. 点击“导入N项”，完成后打开清单。

“导入后在应用中显示未开始的任务”默认开启，便于立即查看明天或稍后才开始的安排。它会打开原 App 的“显示未开始任务”选项；取消勾选时保留原有显示设置。

一次最多200项。若导入页已打开，又分享到一段新文字，会询问是否替换当前草稿，已保存的任务会保留。

## 重复和完成状态

按任务名称、日期、开始和结束时间查重，包含已完成任务；重复项默认不导入。同样任务的备注不会被自动覆盖，修改已有备注请从任务清单中编辑。

原文的 `[x]` 完成项默认不勾选。正常未完成项导入后可在 App 或桌面小部件勾选，完成记录保留在 App 中。

## 桌面小部件

App 设置 → 插件设置 → 添加小部件到主屏幕，或者从手机桌面的小部件列表添加本应用。

选择要显示的清单，关闭显示已完成项。要提前看到尚未开始的安排，保留小部件的“显示未开始任务”设置。带开始、结束时间的条目显示完整时间段；窄尺寸下时间段放在标题下方。

长按小部件可以调整大小；任务较多时可把它拉高。勾选完成后自动隐藏，已完成任务仍保留在 App 内。
